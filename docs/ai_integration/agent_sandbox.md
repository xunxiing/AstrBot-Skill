## 概述
AstrBot 在 v4.12.0 中引入了代理沙箱环境（Agent Sandbox），这是一个改进的代码解释器（Code Interpreter）实现。它为 AI Agent 提供了一个隔离的执行上下文，使其能够通过生成并运行 Python 代码来解决复杂的计算、数据处理或逻辑推理任务。

## 核心机制
1. **能力集成**：沙箱环境作为 Agent 的内置扩展能力，与 `context.tool_loop_agent` 深度集成。当 LLM 判定当前任务需要编程解决时，会自动调用代码解释器工具。
2. **执行流控制**：
    - **代码生成**：LLM 根据用户需求生成 Python 代码片段。
    - **受限执行**：代码在隔离的沙箱中运行，限制了对宿主机文件系统、网络和系统资源的直接访问。
    - **反馈循环**：执行结果（包括标准输出 `stdout`、错误信息 `stderr` 或运行状态）会实时反馈给 LLM，作为下一轮对话的上下文。
3. **安全性设计**：通过代理沙箱环境，AstrBot 确保了即使 LLM 生成了非预期的代码，也不会对主进程或服务器安全造成直接威胁。

## 变更影响分析
- **Agent 逻辑增强**：开发者在使用 `tool_loop_agent` 时，不再需要为每一个细小的数学或逻辑任务编写专门的 `FunctionTool`。Agent 现在具备了通过“即时编程”解决问题的通用能力。
- **系统架构影响**：引入了代码执行的异步等待机制。在 Agent 运行期间，可能会增加 `tool_loop_agent` 的执行步数（`max_steps`）和耗时。
- **最佳实践**：建议在 `system_prompt` 中明确告知 Agent 具备代码执行能力，以便其在处理数据分析、复杂数学题或需要精确逻辑的场景下优先启用沙箱环境。

## 边界与限制
- **环境依赖**：沙箱内可用的 Python 库受限于预装环境。对于需要特定第三方库的任务，仍建议通过自定义插件工具实现。
- **资源配额**：代码执行受到超时时间和内存限制，不适合处理超大规模的计算任务。
